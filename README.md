## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- email-campaign-writer
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/email-campaign-writer /tmp/email-campaign-writer
mkdir -p ~/.claude/skills && cp -r /tmp/email-campaign-writer/skills/email-campaign-writer ~/.claude/skills/
```

**Per project:** copy `skills/email-campaign-writer` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/email-campaign-writer/SKILL.md) into your rules or system prompt.
